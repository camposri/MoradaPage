# Morada Page - Landing Page Imobiliária

Landing page profissional para corretor imobiliário Valmike Junior, desenvolvida com foco em conversão e experiência do usuário.

## 🏠 Sobre o Projeto

Esta é uma landing page moderna e responsiva criada para apresentar os serviços imobiliários do corretor Valmike Junior. A página foi desenvolvida com HTML5, CSS3 (Tailwind CSS) e JavaScript vanilla, priorizando performance e conversão.

## ✨ Funcionalidades

- **Design Responsivo**: Adaptável a todos os dispositivos
- **Barra de Busca Inteligente**: Filtros por tipo de imóvel, preço e localização
- **Carrossel de Destaques**: Apresentação dos melhores imóveis
- **Chatbot Integrado**: Atendimento automatizado com avatar personalizado
- **Formulário de Contato**: Captura de leads otimizada
- **Animações Suaves**: Experiência visual aprimorada

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3 com Tailwind CSS
- JavaScript (ES6+)
- Font Awesome (ícones)
- Google Fonts (Poppins)

## 📱 Seções da Página

1. **Header**: Navegação com menu de categorias e botão Admin
2. **Hero Section**: Chamada principal com CTA
3. **Barra de Busca**: Filtros inteligentes para imóveis
4. **Benefícios**: Cards com vantagens dos serviços
5. **Destaques**: Carrossel de propriedades em destaque
6. **Contato**: Informações e formulário de contato
7. **Footer**: Links úteis e redes sociais
8. **Chatbot**: Assistente virtual flutuante

## 🎨 Design

- **Cores Principais**: Gradiente roxo (#8B5CF6 → #A855F7)
- **Tipografia**: Poppins (Google Fonts)
- **Layout**: Mobile-first, totalmente responsivo
- **Animações**: Transições suaves e efeitos hover
